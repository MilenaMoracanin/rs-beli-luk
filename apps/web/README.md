# RS Beli Luk

Planer za uzgajanje belog luka — Next.js aplikacija sa SQLite bazom.

## Pokretanje lokalno

```bash
npm install
npm run dev
```

Aplikacija: http://localhost:3000

Podaci (checklist, troškovi) se čuvaju u `apps/web/data/beli-luk.db`.

## Struktura

- `apps/web` — Next.js aplikacija
- `packages/shared` — sorte, šabloni zadataka, kalkulacije
